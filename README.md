# Instagram-Wachstum: 50k Follower

Gemeinsame Arbeitsbasis für Account-Analyse, Strategie und Redaktionsplan.
Alles Wichtige steht hier als Datei, damit jede Session (Cloud, Mac, Desktop) auf denselben Stand zugreift.

## Struktur

- `profil.md`: Ausgangslage (Handle, Follower, Bio, Nische, Ziel, verfügbare Zeit)
- `analyse/`: Insights-Auswertungen, Top- und Flop-Posts, Learnings pro Zeitraum
- `konzepte/`: Positionierung, Content-Säulen, Format-Mix
- `redaktionsplan/`: Wochenpläne mit Hooks, Skripten, Karussell-Texten, Status

## Arbeitsweise

1. Vor jeder Session: `git pull origin claude/social-media-50k-follower-90cmhu`
2. Neue Erkenntnisse und Pläne in die passenden Ordner schreiben.
3. Committen und pushen, damit der Stand überall verfügbar ist.
4. Jeden Montag: Kennzahlen der Vorwoche in `analyse/` eintragen und den Plan anpassen.
